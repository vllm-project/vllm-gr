# Contributing to vLLM-GR

<a id="development-setup"></a>

Start with the [contributor guide](docs/contributing/README.md) for documentation
and runtime development. See [pre-commit setup](docs/contributing/pre_commit_setup.md)
for formatting and local checks.

<a id="change-and-validation-workflow"></a>

Follow [Issues, RFCs and pull requests](docs/contributing/README.md#issues-rfcs-and-pull-requests)
to propose a change, sign off your commits and prepare the PR description.
Before submitting, review the [pull request checks](docs/contributing/ci/pr_merge_loop.md)
and the requirements for the target branch.

<a id="pull-request-ci"></a>

For CI results, reruns and checks before merging, see
[pull request checks](docs/contributing/ci/pr_merge_loop.md).

<a id="ai-coding-tools"></a>

For AI-assisted contributions, follow the [AI Usage Policy](docs/contributing/README.md#ai-usage-policy).
