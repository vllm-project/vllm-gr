# Getting started

Get from a fresh environment to your first OneRec request.

## Install and run OneRec

1. Install vLLM-GR for your device. Follow the
   [NVIDIA GPU (CUDA)](installation/gpu.md) or [Ascend NPU](installation/npu.md)
   installation guide, including its runtime verification step.
2. Run your first request with the [quickstart](quickstart.md). It sends a
   short request to OneRec-1.7B and explains the returned candidates.
3. Move on to the [user guide](../user_guide/README.md) to configure Beam
   width, constraints, and serving.

Both devices use OneRec-1.7B and the same Python entry point. Follow the
installation guide and quickstart example for your device.
