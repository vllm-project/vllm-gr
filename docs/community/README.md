# Community

vLLM-GR is developed in the [JiusiServe/vllm-gr repository](https://github.com/JiusiServe/vllm-gr).
Use the project trackers to share reproducible problems, discuss changes and
contribute improvements.

| I want to... | Where to go |
| --- | --- |
| Report a bug or request a feature | [Issue templates](https://github.com/JiusiServe/vllm-gr/issues/new/choose) |
| Discuss or review a proposed change | [Pull requests](https://github.com/JiusiServe/vllm-gr/pulls) |
| Submit code or documentation | [Contributor workflow](https://github.com/JiusiServe/vllm-gr/blob/main/CONTRIBUTING.md) |
| Report a security issue privately | [Security policy](https://github.com/JiusiServe/vllm-gr/blob/main/SECURITY.md) |
| Understand attribution and licenses | [Legal guidance](legal/README.md) |

For a runtime issue, include the revision, environment, model identity, failing
command and original exception. The [troubleshooting guide](../getting_started/troubleshooting.md)
lists useful evidence. Remove credentials and private input data before posting.
